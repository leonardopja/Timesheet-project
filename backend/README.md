# Timesheet API

This backend stores users and shifts in MongoDB Atlas.

## Environment

Create a `.env` file with:

```env
PORT=3000
DB_NAME=timesheetDB
MONGO_URI=mongodb+srv://<username>:<password>@cluster-timesheet.gpfug8r.mongodb.net/?appName=Cluster-timesheet
```

## Run

```bash
npm install
npm run dev
```
